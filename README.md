# ⚔️ EPWR | نبرد حماسی 💎

یک ربات تلگرام پیشرفته برای بازی نقش‌آفرینی آنلاین (MMORPG) با تم نبردهای حماسی و فانتزی.

## 🎮 ویژگی‌ها

- 🗡️ سیستم نبرد نوبتی با استراتژی عمیق
- 🏰 قلعه‌سازی و مدیریت منابع
- 👥 بازی چندنفره آنلاین
- 📊 سیستم رتبه‌بندی و لیگ
- 🎁 جوایز روزانه و مأموریت‌های ویژه
- 💬 چت داخلی و سیستم اتحادها

## 🚀 شروع سریع

### پیش‌نیازها

- Node.js 18+
- npm یا yarn
- توکن ربات تلگرام

### نصب

1. کلون کردن مخزن:
```bash
git clone https://github.com/ImPMUFO/EPWR.git
cd EPWR
نصب وابستگی‌ها:
npm install
تنظیم متغیرهای محیطی:
cp .env.example .env
# ویرایش فایل .env و وارد کردن توکن ربات
اجرای ربات:
npm start
📁 ساختار پروژه
EPWR/
├── api/          # توابع API و وب‌هوک‌ها
├── src/          # کد اصلی ربات
├── sql/          # اسکریپت‌های دیتابیس
├── .env.example  # نمونه فایل محیطی
└── package.json  # وابستگی‌ها و اسکریپت‌ها
🛠️ تکنولوژی‌ها
Backend: Node.js
Database: MySQL
Deployment: Vercel
Bot Framework: Telegraf/Node-telegram-bot-api
