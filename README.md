# ⚔️ EPWR | نبرد حماسی

> 🎮 **بازی استراتژیک و نقش‌آفرینی تلگرامی** با قهرمان‌ها، ارتش، قلمرو، اقتصاد پویا، تجارت، اتحادها و نبردهای PvP و PvE.

**EPWR** یک بازی استراتژیک چندسیستمی است که تمام تجربه‌ی بازی را مستقیماً داخل تلگرام ارائه می‌کند.  
بازیکن قلمرو خودش را توسعه می‌دهد، قهرمان جمع می‌کند، ارتش می‌سازد، منابع تولید می‌کند، با دیگر بازیکنان معامله می‌کند، به دشمنان حمله می‌کند و برای رسیدن به رتبه‌های بالاتر رقابت می‌کند.

## 🌍 دنیای EPWR

در EPWR، بازیکن فقط یک جنگجو نیست؛ **فرمانده یک قلمرو زنده** است.

از ساخت اولین ساختمان و استخدام اولین سرباز، تا تشکیل اتحاد و ورود به جنگ‌های بزرگ، هر تصمیم روی اقتصاد، قدرت و پیشرفت بازیکن اثر می‌گذارد.

### 🔥 چرخه اصلی بازی

```text
🏰 ساخت و ارتقا
       ↓
🌾 تولید منابع
       ↓
💰 مدیریت اقتصاد
       ↓
🦸 جذب و ارتقای قهرمان
       ↓
🪖 تشکیل ارتش
       ↓
⚔️ نبرد و فتح
       ↓
🏆 دریافت پاداش و XP
       ↓
📈 توسعه بیشتر قلمرو
```

## ✨ ویژگی‌ها

### 🦸 قهرمان‌ها
- قهرمان‌های منحصربه‌فرد با نام، تصویر و مشخصات اختصاصی
- سیستم قدرت و سلامتی

- سرباز اختصاصی برای هر قهرمان

### 🪖 سیستم سربازها
هر قهرمان می‌تواند نوع خاصی از سرباز را در اختیار داشته باشد.

ویژگی‌های قابل مدیریت:
- قدرت سرباز
- ظرفیت
- ارتباط با قهرمان
- تأثیر در محاسبه قدرت ارتش

### ⚔️ نبرد
- نبرد با NPC
- نبرد PvP بین بازیکنان
- محاسبه قدرت طرفین
- پاداش و غنیمت

- سیستم استراحت قهرمان‌ها پس از نبرد

### 🛌 سیستم استراحت
در EPWR قهرمان‌ها به‌سادگی «نمی‌میرند».

قهرمان آسیب‌دیده وارد **پادگان** می‌شود و با توجه به قدرت و شرایطش، پس از مدت مشخصی دوباره آماده نبرد خواهد شد.

> 💡 این سیستم باعث می‌شود شکست پایان بازی نباشد و مدیریت زمان و پادگان اهمیت پیدا کند.

# 🚀 راه‌اندازی

## 1️⃣ ساخت ربات تلگرام

از طریق [@BotFather](https://t.me/BotFather) یک Bot ایجاد کنید و Token آن را دریافت کنید.

---

## 2️⃣ ساخت دیتابیس

یک پروژه در [Supabase](https://supabase.com) ایجاد کنید.

سپس SQLهای موجود در پوشه زیر را اجرا کنید:

```text
sql/
```

حداقل اسکیمای اولیه:

```text
sql/001_initial_schema.sql
```

> در صورت وجود migrationهای جدید، آن‌ها را نیز به ترتیب اجرا کنید.

---

## 3️⃣ نصب وابستگی‌ها

```bash
npm install
```

---

## 4️⃣ تنظیم Environment Variables

فایل `.env.example` را به `.env` تبدیل کنید و مقادیر موردنیاز را وارد کنید.

| متغیر | توضیح |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات از BotFather |
| `SUPABASE_URL` | URL پروژه Supabase |
| `SUPABASE_SERVICE_KEY` | Service Role Key برای عملیات سمت سرور |
| `ADMIN_ID` | شناسه عددی مدیر اصلی تلگرام |

### ⚠️ نکته امنیتی

**Service Role Key را هرگز در Frontend، GitHub یا فایل‌های عمومی قرار ندهید.**

فایل `.env` نیز باید در `.gitignore` قرار داشته باشد.

---

## 5️⃣ اجرای محلی

```bash
npm run dev
```

یا بسته به اسکریپت‌های پروژه:

```bash
npm start
```

---

# ▲ استقرار روی Vercel

1. Repository را به Vercel متصل کنید.
2. Environment Variables را وارد کنید.
3. پروژه را Deploy کنید.
4. Webhook ربات را به Endpoint مربوط به `api/webhook.js` متصل کنید.

پس از استقرار، ربات می‌تواند Updateهای تلگرام را از طریق Webhook دریافت کند.
