# ⚔️ EPWR | نبرد حماسی

**بازی استراتژیک تلگرامی با قهرمان‌ها، جنگ، ساختمان‌ها و اقتصاد پویا**

---

## 🎮 درباره بازی

**EPWR** یک بازی استراتژیک و نقش‌آفرینی در تلگرامه که توش قهرمان جمع می‌کنی، ارتش می‌سازی، سرزمین‌ها رو فتح می‌کنی و با بازیکن‌های واقعی می‌جنگی!

### ✨ چرا EPWR؟

- 🦸 **قهرمان‌های منحصربه‌فرد** با اسم، تصویر پیکسلی، اسکین و سلاح اختصاصی
- 🪖 **سرباز اختصاصی** برای هر قهرمان با قدرت و ظرفیت متفاوت
- 🛌 **سیستم استراحت** به جای مرگ: قهرمان‌ها در پادگان بهبود می‌یابند
- ⚔️ **جنگ NPC و PvP** با سیستم قدرت هوشمند و دزدی سکه
- 🏗️ **۹ ساختمان قابل ارتقا** (قلعه، دیوار، پادگان، آهنگری، مرغداری و...)
- 🍞 **زنجیره تولید**: گندم → آرد → نان
- 🐫 **بازارچه**: خرید و فروش منابع و قهرمان بین بازیکن‌ها با قیمت دلخواه
- 🤝 **اتحاد** با خزانه، جنگ اتحادها، جایزه روزانه و لینک دعوت
- 📜 **مأموریت‌های روزانه** با جوایز ویژه
- 🔔 **اعلان‌های هوشمند** برای حملات و گرسنگی
- 👑 **پنل مدیریت قدرتمند** داخل ربات (بدون نیاز به کد)

## 🚀 راه‌اندازی

### ۱. دیتابیس (Supabase)
- یک پروژه در [Supabase](https://supabase.com) بساز
- اسکیمای `sql/001_initial_schema.sql` و SQLهای ارتقا رو اجرا کن

### ۲. دیپلوی (Vercel)
- ریپو رو به Vercel وصل کن
- متغیرهای محیطی رو تنظیم کن

### 🔐 متغیرهای محیطی

| متغیر | توضیح |
|-------|--------|
| `TELEGRAM_BOT_TOKEN` | توکن ربات از BotFather |
| `SUPABASE_URL` | آدرس پروژه Supabase |
| `SUPABASE_SERVICE_KEY` | کلید سرویس Supabase |
| `ADMIN_ID` | آیدی عددی تلگرام مدیر |

---

## 👑 پنل مدیریت

با دستور `/admin` (فقط برای ADMIN_ID) به پنل دسترسی داری:

- 🦸 **مدیریت قهرمان‌ها**: ساخت، ویرایش قدرت/سلامتی/قیمت/کمیابی/نوع/سرباز/پادگان لازم، تصویر، مخفی/حذف
- 🎁 **کد هدیه**: ساخت، لیست، فعال/غیرفعال، حذف
- 💰 **سکه به کاربر** و **هدیه به همه**
- 📢 **پیام همگانی** به کاربران و گروه‌ها
- 📊 **آمار** بازی
- 🖼 **تنظیم تصاویر** قهرمان‌ها و قلمرو
